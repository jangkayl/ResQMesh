# Phase 2: mesh routing and payloads

Historical milestone: SYSTEM topology exchange, a neighbor graph in MeshRouter, forwarding in PayloadDispatcher, and trace-route UI were developed. Connection-priority and write-no-response choices were added as performance attempts.

Do not infer guaranteed multi-hop delivery, a complete distance-vector protocol, a fixed 11 ms radio interval, or symmetric high-speed transfers from this milestone. Current tests and repair gates are in [BLE repair](../ble_repair_pipeline.md).
